# Security policy

WarrantX is pre-audit software. Testnet use is supported; mainnet use with material funds is not recommended until an independent audit is published.

Report vulnerabilities privately through GitHub's **Security > Report a vulnerability** flow. Include the affected commit, impact, reproduction steps, and any suggested mitigation. Do not open a public issue for an unpatched vulnerability.

Maintainers will acknowledge a complete report within five business days and coordinate disclosure after a fix is available.
