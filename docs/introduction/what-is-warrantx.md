# What is WarrantX?

WarrantX is an open-source treasury application for organizations using Stellar. It combines a web dashboard, API, event indexer, TypeScript SDK, and Soroban contracts so a treasury can enforce who may spend, how much they may spend, and when additional approvals are required.

WarrantX is pre-audit software. Use testnet for evaluation. A mainnet deployment should follow an independent contract audit and operational review.
